# Bastion Medieval

Ein textbasiertes Fantasy-Rollenspiel im mittelalterlichen Stil für Android.
Man bewegt sich per freier Texteingabe durch eine große, tiefe Welt; wer nicht
weiter weiß, bekommt Vorschläge als Knöpfe.

- Native Android-App (Kotlin, Jetpack Compose)
- Vollständig offline, ohne Internetzugriff
- Deutsch als Hauptsprache, Englisch als vollständige Übersetzung

Das Grundgerüst folgt im nächsten Commit.
